# 暗黑重铸 / Darkforge 更新源

这个仓库只放暗黑重铸整合包的更新包和版本清单（latest.json），给整合包启动器的「检查更新」用。
Gitee 和 GitHub 上各有一份，内容一样：启动器两边一起试，哪边快用哪边。

- 玩家不用来这里下载：打开启动器 → 工具 →「检查更新」。
- 也可以在「发行版 / Releases」里手动下载更新包，用启动器的「导入更新包」导入。
